# 产品需求文档 PRD

版本：1.0；编写日期：2026-10-22（Asia/Shanghai）。

## 1. 目标与依据

在新目录重写彩票开奖追踪与邮件通知系统。用户提供的 AGENTS.md 决定技术架构、代码分层、安全、测试和交付标准；历史聊天只作为彩票业务参考，不实施文档示例中的公司客户/订单模块。

主要目标：明确日期、彩种、官方期号和奖金；自动通知只发送确定中奖；手动测试能对比官方最新结果；长期号码可审计、可追溯；上线可回滚。

## 2. 角色

| 角色 | 允许范围 |
| --- | --- |
| 管理员 ADMIN | 全部号码、编辑删除、同步、邮件测试、邮件配置、系统状态 |
| 只读 VIEWER | 读取自己负责的号码/邮件与公共开奖结果；不能写入 |
| 未登录 | 只能登录和读取无敏感信息的健康状态 |

生产默认仅初始化管理员。角色由数据库配置，未新增未经请求的员工管理模块。服务层检查权限及负责人范围，不能靠隐藏按钮授权。

## 3. 功能范围与验收

| 模块 | 实现目标 | 验收重点 |
| --- | --- | --- |
| 仪表盘 | 理论累计中奖、已标记购买奖金、有效号码数、开奖数、明细与趋势 | 测试邮件不计入累计；未知奖金不按零计算 |
| 固定号码 | 新建、编辑、暂停/启用、软删除、版本历史、手动测试发送 | 红蓝区独立；并发编辑冲突提示；删除二次确认 |
| 临时号码 | 指定未来预计开奖日的单期号码 | 校验彩种开奖星期与未来时间；支持软删除 |
| 开奖日历 | 月视图、彩种颜色、日期下的历史号码 | 大号日期、今日标记、移动端横向滚动 |
| 开奖结果 | 官方期号与日期分列、号码、状态、奖金数据情况 | 不显示来源/操作列；不提供比较裁决按钮 |
| 列表 | 页码、彩种、状态、日期、关键词组合过滤 | 页长 20，切换筛选回第一页 |
| 彩种规则 | 选号范围、奖级命中组合、官方说明链接 | 奖金从本期数据读取，缺失不估算 |
| 邮件 | 自动中奖通知、手动号码测试、SMTP 测试、任务及结果日志 | 只有自动邮件受中奖门槛；不确定发送结果不自动重发 |
| 系统状态 | 定时任务开关、最后同步、审计记录 | 不泄露密钥、授权码和会话 |

## 4. 核心流程

1. 管理员录入号码，服务端校验数量、范围、重复球和日期。
2. 号码和完整配置写为版本；每期按截止前最新版本形成不可变快照。
3. 定时同步官方开奖；记录官方期号、日期、号码、奖级金额与证据版本。
4. 同号码奖金补全更新匹配；不同号码冲突转待核实，停止自动统计/通知。
5. 明确中奖且奖金完整、配置允许时生成唯一自动邮件任务。
6. 邮件投递保存状态和尝试记录；响应不确定的任务由人工先检查收件箱。

手动发送直接访问官方源选择最新日期，不依赖本地已确认/异常状态；邮件明确标记手动测试、期号、日期、每注结果及总金额。

## 5. 非功能需求

- 敏感数据仅在服务端；数据库会话；生产 HTTPS + Secure/HttpOnly/SameSite Cookie。
- 金额使用 Decimal 和整数分，JSON 金额用字符串。
- 数据外键、唯一键、校验约束保护事务和幂等。
- 官方网络请求限时、限量、固定 URL，单彩种故障隔离。
- 迁移仅 migrate deploy；新数据库与旧 SQLite 独立。
- 不向外部服务上传旧版业务数据。
- 文件/模块有业务意图注释，复杂状态转换明确说明。

## 6. 本期不包含

复式、胆拖、追加、倍投、代购、支付、税费计算、历史规则全库、公开注册、人工裁决、自动迁移旧密码。2026-10-23 另行核对并迁入启用号码与 SMTP 设置，保留原系统备份；旧历史中奖统计和发送日志不进入新版。

## 7. 发布门槛

类型检查、Lint、单元/隔离库集成测试、浏览器关键流程、生产构建；服务器连接、迁移、容器健康、HTTPS 和登录验收。网络不通时不能宣称上线完成。
