# 操作手册

## 登录

使用管理员初始化时指定的账号和密码。访问地址由部署管理员提供；首次访问内网 HTTPS 站点时，按部署手册核对并信任内部 CA 根证书。

## 固定号码

1. 点击“新增号码组”，填写名称和彩种。
2. 选择或手输 YYYY-MM-DD 起始日期。每个圆格输入两位号码（如 01）；输入有效后自动跳到下一格，红区填完会跳到蓝区。超范围或同一区重复会立即提示，并停留在当前格供修改。
3. “添加一注”增加一组号码格；每组表示一注，不能混用彩种。留空或未填满的号码不能保存。
4. 收件邮箱留空将使用默认收件人；默认仅追踪，确实购买后才勾选购买。
5. 保存后可编辑、暂停、删除或查看历史。删除只停止未来追踪，历史和日志仍保留。
6. 点击“发送”并确认，会实时对比官方最新可用期次。无论胜负都会生成测试邮件，不计入累计奖金。

测试提示“已加入队列”不是“已经送达”；请在邮件任务中确认 SENT。官方接口失败会明确提示，不会拿本地旧期冒充最新一期。

## 临时号码

填写预计开奖日和本期号码，支持编辑与删除。日期必须是该彩种预计开奖星期且未到本系统截止点。休市及延期仍以官方公告为准；预计期次不伪造官方期号。

## 开奖结果与筛选

彩种、状态、起止日期和官方期号可组合查询。点击筛选回第一页，重置清空条件。官方期号与日期分开显示，不再包含来源/操作列。管理员可“同步官方结果”；两彩种同步结果分别反馈。

## 开奖日历

通过月份选择器或左右箭头切换；“本月”回当前月份。红色为双色球、蓝色为大乐透，日期下展示历史期号及号码。手机横向滚动月视图，不把号码挤成无法识别的小点。

## 仪表盘

“累计理论中奖”包括有效追踪记录；“已标记购买的奖金”仅统计明确购买的快照，两者均是税前理论奖金，不代表到账收益。未知金额单独提示；手动测试不计入。冲突结果不计入统计。

## QQ 邮箱

SMTP 主机 smtp.qq.com；端口选 465 / SSL-TLS；邮箱账号和发件地址均填完整 QQ 邮箱；新授权码填 QQ 邮箱设置里生成的 SMTP 授权码，不填 QQ 登录密码。密码留空保持已保存值。默认收件人可填多个，逗号分隔。

先保存，再“发送测试邮件”；发送使用已保存值。真实投递还需要服务器 MAIL_DELIVERY_ENABLED=true。要自动通知中奖，还需打开本页“启用自动中奖通知”。测试邮件会发给默认收件人，发送前请确认地址。

## 任务与异常

| 状态 | 含义 / 操作 |
| --- | --- |
| 待发送 | 等待后台处理；检查投递环境开关和 SMTP |
| 发送中 | 已领取，不能安全撤销 |
| 已发送 | SMTP 已接受；最终收件请检查邮箱及垃圾箱 |
| 发送失败 | 认证/连接明确失败，检查配置 |
| 结果待核实 | 可能已经发送，先检查收件箱，切勿连续重复点击 |
| 已取消 | 删除/暂停或开奖冲突取消待发自动邮件 |

系统状态页提供最后同步结果及最近审计记录。官方不可用时可稍后再次同步；不推荐人工修改数据库猜测结果。
