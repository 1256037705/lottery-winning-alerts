本文只记录可安全公开的工程验收信息，不记录服务器地址、账户、证书指纹、真实号码、收件人或邮件授权码。生产环境的具体检查记录应保存在受控运维系统中。

## 本地验证

- Node.js 24、pnpm 11.25.0；锁文件安装与 Prisma Client 生成通过。
- TypeScript strict、ESLint、30 项单元测试与生产构建通过。
- 隔离 PostgreSQL 测试库完成 2 项迁移；服务集成测试覆盖权限、对象级范围、版本冲突、幂等与邮件异常状态。
- Chromium E2E 覆盖登录拦截、号码新增/编辑/删除、日期筛选、日历、移动导航及错误密码。
- 圆形号码格验证双色球 6+1 与大乐透 5+2：有效双位号码自动跳格，越界、重复和未完成号码被拦截。
- 多注弹窗在 390px 手机和 1280×700 桌面视口检查：表单主体独立滚动，最后一注及保存操作可用。

## 部署验收清单

实际部署时应逐项验证，不应仅凭本地构建宣称生产可用：

1. 数据库迁移状态与容器健康，确认数据库端口未公开。
2. 用受信任证书访问 HTTPS 健康接口，并验证登录、会话和退出。
3. 只导入经授权的号码和配置；核对收件人、购买标记、追踪起始日期及版本。
4. 官方结果同步、中奖判定与任务状态；SMTP 发送需单独确认，不把服务器接受等同于最终收件。
5. 备份数据库和加密密钥，并在独立环境验证恢复流程。

生产凭据、数据库、备份、证书以及含真实业务数据的日志均不得提交 GitHub。
