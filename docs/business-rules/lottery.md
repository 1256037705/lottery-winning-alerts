# 彩票追踪与邮件规则

## 选号与版本

双色球：6 个不同红球 1–33，1 个蓝球 1–16。大乐透：5 个不同前区球 1–35，2 个不同后区球 1–12。仅支持单式基本投注，每组 1–100 注，保存时区内排序；每注独立统计。

每次编辑或状态变化写新版本，包含号码、状态、业务日期、收件人及购买标记。已有快照不变。暂停/删除取消尚未投递的自动通知；已发送与发送中任务不可撤回。

## 日历与截止点

沿用旧业务的 21:30（Asia/Shanghai）预计查询/快照时间，而不是擅自声称官方售票截止时间。双色球预计周二/四/日，大乐透周一/三/六。预计日历不生成官方期号，休市延期以实际公告为准。

快照选择该期截止前最新完整版本，避免事后编辑改变历史。新建号码不得追溯创建前日期；临时号码只选尚未截止且星期匹配的预计开奖日。

## 判奖与金额

规则版本：双色球 2026-02-01 起，大乐透 2026-02-02 起。更早期次不套用当前规则判奖。

每注只取最高奖级。本期奖金来自官方奖级表。浮动奖、奖池影响的固定奖和福运奖不从旧数据猜测。福运奖缺少启动/金额证据时保持待确认，不当作确定未中奖。各奖级命中组合见网页“彩种规则”与 matching.ts。

金额以整数分计算、Decimal 持久化；序列化为两位小数字符串。不含税费、不代表银行到账。未中奖明确 0.00；奖金不明 NULL。

- [广东福彩双色球规则调整公告](https://www.gdfc.org.cn/datas/content/content_280542.html?subjectID=14)

## 官方同步与冲突

固定 URL、15 秒超时、2 MB 响应上限。两个彩种各自处理；失败不捏造结果。返回数组重新按日期降序排序，不依赖接口顺序。

同号码新增奖金可补全。不同号码或期号冲突保留证据并标记 CONFLICT，不覆盖已确认号码、不自动裁决；冲突期次不计入仪表盘，也停止待发自动邮件。

## 邮件

自动：只有确定中奖、所有本次金额明确、号码当前启用、自动开关打开且有收件人时生成任务。一个快照每期最多一个自动任务。发送环境开关为 false 时只入队。

手动：读取当前号码版本 + 官方最新可用期次，胜负都发测试邮件，列出期号、日期、每注命中及金额；未知奖金明确待确认，不能给出虚假数值。此类任务不生成统计 MatchRecord。

安全投递：PENDING → SENDING → SENT / FAILED / UNCERTAIN。发送中崩溃或 SMTP 返回不明转 UNCERTAIN，不盲目重试。明确失败也由用户核对配置后重新发起测试，不无限重试。
